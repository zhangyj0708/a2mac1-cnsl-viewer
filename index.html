ℹ️ 关于

A2MAC1 CNSL 尺寸爬取与分析平台

版本: 0.6.9

从 A2MAC1 平台自动提取汽车 Console（中控台）的尺寸数据和 3D 点云文件， 支持多车型对标分析和部件适配判定。

API 参考

API 逆向分析参考了 opencli-plugin-a2mac1（Node.js CLI 插件）， 吸收了 VOP 层级树节点 ID、POST 尺寸数据 API 等关键信息。 详见 data/vop-nodes.json。

工作流程

步骤操作说明
1在 A2MAC1 打开目标车型 3D Data v3 页面需登录
2F12 → Console → 粘贴提取脚本自动提取所有数据
3运行 __CNSL_exportJSON() 下载 JSON包含车型+尺寸+文件链接
4回到本平台 → 数据库 → 导入 JSON自动填充所有数据
5搜索车型、查看尺寸、对标分析所有数据已就绪
